# Marke

Hier hinein gehören die Bilddateien. Solange eine fehlt, zeigt die Anwendung
einen Platzhalter — sie bleibt also benutzbar, sieht nur noch nicht fertig aus.

Zum Austauschen genügt es, die Datei mit dem passenden Namen hier abzulegen.
Am Code muss dafür nichts geändert werden.

| Datei | Wo es erscheint |
|---|---|
| `logo.png` | Seitenleiste und Kopfzeile am Handy |
| `maskottchen-winken.png` | Begrüßung oben rechts |
| `maskottchen-counter.png` | Kachel Counter |
| `maskottchen-service.png` | Kachel Service |
| `maskottchen-kueche.png` | Kachel Küche |
| `maskottchen-mechanik.png` | Kachel Mechanik |
| `maskottchen-profil.png` | Benutzerkarte und Profilseite |

Empfehlung: PNG mit durchsichtigem Hintergrund, etwa 512 × 512 Pixel. Größer
schadet nicht, kostet aber Ladezeit auf dem Tablet.

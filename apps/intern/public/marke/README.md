# Marke

Was hier liegt, benutzt das Programm unmittelbar. Eine Datei austauschen genügt —
am Code ist dafür nichts zu ändern.

## Vorhanden

| Datei | Wofür |
|---|---|
| `logo.svg` | Wortmarke. Wird als Maske benutzt: sichtbar ist nicht die Farbe der Datei, sondern die der Umgebung — golden im Programm, schwarz auf dem Ausdruck. Der Rahmen ist auf die Zeichnung zugeschnitten (Original 1773×1773, jetzt 1534×857); die Pfade sind unverändert. |
| `maskottchen-winken.png` | Pinny, winkend. Steht vorläufig auch für das Profilbild. |

## Erwartet

Sobald eine dieser Dateien hier liegt, erscheint sie von selbst; solange sie
fehlt, steht an ihrer Stelle ein Notbehelf, und die Seite bleibt benutzbar.

| Datei | Wo sie erscheint |
|---|---|
| `maskottchen-counter.png` | Werkzeuge des Counters |
| `maskottchen-service.png` | Werkzeuge des Service |
| `maskottchen-kueche.png` | Werkzeuge der Küche |
| `maskottchen-mechanik.png` | Bahnwartung |
| `maskottchen-profil.png` | Profil, Kopfzeile, Benutzerverwaltung |

## Worauf es ankommt

**Durchsichtiger Hintergrund.** Ohne ihn sitzt die Figur in einem weißen Kasten
mitten im dunklen Bild. Freistellen kann das Programm nicht.

**Kopf oben in der Mitte.** In kleinen Feldern — Kopfzeile, Profil, Liste — wird
auf den Kopf beschnitten (oberes Zehntel bis Mitte). Sitzt die Figur weit unten
im Bild, erscheint dort eine Schulter.

**Größe.** Rund 500 Punkte lange Kante genügen; alles darüber macht nur die Seite
schwer. Die gelieferten Fassungen in Originalgröße liegen unter
`apps/intern/marke-quellen/`.
